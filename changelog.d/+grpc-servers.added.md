Added gRPC servers: `GrpcProject.grpc`, with `grpc.api`, the registry of the services, `grpc.bindings`, which of them each server serves, and `grpc.servers`, whose `default` is a component serving the services of `grpc.bindings.default` (every implemented service of the API by default), configured by `GRPC_DEFAULT_LISTEN_HOST`, `GRPC_DEFAULT_PORT`, `GRPC_DEFAULT_MAX_CONCURRENT_RPCS` and `GRPC_DEFAULT_SHUTDOWN_GRACE`. A `GrpcService` names a service and its `_pb2_grpc` module (`class GreeterService(GrpcService, full_name="demo.Greeter", module=demo_pb2_grpc)`), finds the code grpcio generates for it and creates its optional `SERVICER`, a `GrpcServicer`; `BaseGrpcServer` and `BaseGrpcBinding` are the bases of other servers and bindings.
